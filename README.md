# Bakery Image Slider

https://kriss2012.github.io/bakery-slider/

## Features

- **Hero Section**: A large banner displaying a rotating image slider. Features a centered overlay with the bakery name and a call-to-action button.
- **Navigation**: Sticky header with navigation links and a "Contact Us" button.
- **Footer**: Simple footer with social media links and copyright information.

## Tech Stack

- **HTML5**
- **CSS3**

## Getting Started

1.  Clone the repository:
    ```bash
    git clone https://github.com/kriss2012/bakery-slider.git
    ```
2.  Open the `index.html` file in your web browser.
